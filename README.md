# 儿童英语学习 · 角色扮演

一个面向 **6–8 岁儿童** 的英语启蒙 PWA（纯静态网页，无需安装、手机浏览器直接打开即可用）。

## 它怎么玩

- **看漫画对话**：每集是一页小漫画，展示角色间的英文对话场景。
- **选角色扮演**：孩子选一个角色，轮到谁就说谁的台词。
- **看中文说英文**：屏幕给出中文意思，孩子试着说出对应英文。
- **点开答案朗读**：点一下播放标准美式发音，跟着读。
- **结算星星**：完成一集获得星星，进度自动保存在本机。

故事主线为《森林小镇大冒险》，共 40 集，分 6 个篇章；另有第一阶段 40 个基础对话场景（角色扮演版）。

## 角色（动物化一家人 + 小伙伴）

- 兔子一家：莉莉兔、兔妈妈、兔爸爸、兔奶奶
- 熊一家：汤姆熊、熊妈妈、熊爸爸、熊奶奶
- 小伙伴：鸮老师、龟奶奶，以及乐美、诗雅、爱心萌可

## 技术说明

- 纯前端：HTML + CSS + 原生 JavaScript，无构建步骤、无后端。
- 离线可用：通过 `manifest.json` 支持 PWA 安装到主屏；音频与图片均为本地资源。
- 进度存储：浏览器 `localStorage`（键名 `kids_english_roleplay_v1`）。
- 音频：每句对白配有正常语速与慢速两版，由系统语音合成 + 兜底朗读三层保障。

## 目录结构

```
index.html          第二阶段故事版（默认首页）
roleplay.html       第一阶段基础对话版
story.html          兼容旧链接入口
story-app.js        故事版核心逻辑
story-data.js       40 集故事数据（对白/旁白/角色）
chars.js / scenes.js / data-lessons.js  第一阶段资源
style.css / app.js  第一阶段样式与逻辑
manifest.json       PWA 清单
使用说明.md         家长使用说明
assets/             图片资源（角色立绘 chars/、场景 scenes-v2/ 等）
audio/              对白与旁白音频（mp3，含慢速版）
```

## 本地预览

直接用浏览器打开 `index.html` 即可；或在本目录起一个静态服务器，例如：

```
python -m http.server 8080
```

然后访问 http://localhost:8080/
